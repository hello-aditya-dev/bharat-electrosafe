# Bharat Electrosafe Website

This ZIP contains the complete Bharat Electrosafe website source code.

## Technology

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + shadcn/ui
- **Email:** SMTP via Nodemailer (Hostinger)

## Project Root

The project root is the folder containing this README file. You should see:

```
src/
public/
package.json
package-lock.json
next.config.ts
tsconfig.json
.env.example
README-HOSTINGER.md
```

## Hosting: Hostinger Business → Node.js Web App

### Step 1: Upload Files

1. Log in to your Hostinger hPanel
2. Go to **Advanced → Node.js**
3. Create a new Node.js application (**Node.js version 20.9.0 or later** — Next.js 16 requires Node.js >=20.9.0)
4. Upload the contents of this ZIP to the application root directory

### Step 2: Install Dependencies

```
npm ci
```

### Step 3: Build

```
npm run build
```

### Step 4: Start

Set the start command to:

```
npm run start
```

## EMAIL / CONTACT ENQUIRY SETUP

The contact form sends enquiries via SMTP to your business email inbox.

### Required Environment Variables

Set these in **Hostinger → Node.js → Environment Variables**:

| Variable | Description |
|---|---|
| `SMTP_HOST` | SMTP server (e.g. `smtp.hostinger.com`) |
| `SMTP_PORT` | Port number (`587` for STARTTLS, `465` for SSL) |
| `SMTP_USER` | Your business email account (e.g. `swf@bharatelectrosafe.com`) |
| `SMTP_PASSWORD` | Your email account password — **enter this in Hostinger only, never in code** |
| `SMTP_SECURE` | `true` for port 465 (SSL), `false` for port 587 (STARTTLS) |
| `MAIL_FROM` | Sender address (should match SMTP_USER, e.g. `swf@bharatelectrosafe.com`) |
| `MAIL_TO` | Recipient inbox for enquiries (e.g. `rakesh@bharatelectrosafe.com`) |
| `MAIL_CC` | Optional CC recipient (e.g. `vishnu@bharatelectrosafe.com`) — leave empty if not needed |

### Example (placeholder values only):

```
SMTP_HOST=smtp.hostinger.com
SMTP_PORT=587
SMTP_USER=swf@bharatelectrosafe.com
SMTP_PASSWORD=<enter your actual password in Hostinger>
SMTP_SECURE=false
MAIL_FROM=swf@bharatelectrosafe.com
MAIL_TO=rakesh@bharatelectrosafe.com
MAIL_CC=vishnu@bharatelectrosafe.com
```

### How It Works

1. Visitor fills the contact form on the website
2. The Next.js server sends the enquiry via SMTP to `MAIL_TO`
3. The visitor's email is set as the Reply-To address
4. You receive the enquiry in your inbox and can reply directly to the visitor

### Testing After Deployment

1. Open your website's Contact page
2. Fill in the form with test data
3. Submit
4. Check the `MAIL_TO` inbox for the enquiry email

## Other Environment Variables

| Variable | Required | Description |
|---|---|---|
| `ALLOW_INDEXING` | Yes | Set to `true` when ready for search engines to index the site |
| `NEXT_PUBLIC_SITE_URL` | Recommended | Your production domain (e.g. `https://bharatelectrosafe.com`) |
| `TURNSTILE_SECRET_KEY` | Optional | Cloudflare Turnstile bot protection (leave empty to disable) |
| `UPSTASH_REDIS_REST_URL` | Optional | Distributed rate limiting (leave empty for in-memory) |
| `UPSTASH_REDIS_REST_TOKEN` | Optional | Distributed rate limiting token |
